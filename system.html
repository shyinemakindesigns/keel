    Animation library

    Twelve hand-authored Lottie animations and four data-bound SVG charts. Each Lottie has a light and a dark file with identical keyframes, and a static SVG fallback of its settled frame. Nothing plays until you ask.

    Rive library

    Specification only; no .riv files exist. Four components are specified as state machines with exact input names, and each has a working web implementation that uses those inputs today: the Equilibrium Indicator (steadinessValue, isInteracting, isLoading, hasUpdated), the Interactive Savings Goal, the Onboarding Equilibrium and the Scenario Visualization. Read the specification.

    Engineering

    • Components: assets/js/keel-lottie.js (player), assets/js/keel-charts.js (data-bound charts), assets/css/components.css (rows, chips, chart parts). The app and the case study both use them.
    • Loading: lottie-web loads on first need; each JSON is fetched once and only within 300px of the viewport; playback pauses off-screen and in hidden tabs.
    • Budget: every Lottie under 20 KB raw; all 24 files total 30 KB gzipped.
    • Accessibility: named animations are role="img" with a label; decorative ones are hidden; every animation has a static end state; charts have text equivalents.
    • Build: python3 source/lottie/build.py regenerates the library; node source/lottie/gen_specs.js regenerates the specs.
    • Reports: QA, accessibility and performance · Animation specifications and storyboards
